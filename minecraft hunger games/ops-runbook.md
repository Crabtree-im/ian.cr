# Operations Runbook

## Pre-Event Checklist
- Confirm server version and plugin compatibility
- Confirm anti-cheat configuration
- Validate approved roster export
- Load test with bots or staged players
- Verify spawn points and chest markers
- Verify resource pack delivery

## Event-Day Checklist
- Lock server to approved whitelist
- Open check-in window
- Run readiness checks (TPS, memory, plugin status)
- Start match countdown protocol
- Monitor eliminations and dispute reports

## Incident Handling
- Lag spike protocol
- Crash recovery protocol
- Payment/registration dispute protocol
- Rule violation escalation path

## Post-Event
- Export logs and results
- Reconcile payments/participation
- Publish leaderboard and recap
- Record lessons learned for next event
