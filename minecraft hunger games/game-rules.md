# Game Rules Draft

## Match Format
- Up to 100 players
- 4 sections / biomes
- 4 cornucopia spawn groups

## Lives System
- Each player starts with 3 lives
- Any death cause removes 1 life
- At 0 lives: player is eliminated and removed from active competition

## Start Sequence
- Players are assigned to designated start blocks
- Countdown begins after all participants are locked
- Early movement penalty: explosion + life loss

## Win Condition
- Last active player (or team format if adopted later)

## Fairness Notes
- 3-life system improves value for paid participants
- Spawn balancing must be deterministic and auditable
