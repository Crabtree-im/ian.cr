# Minecraft Hunger Games Master Plan

## Vision
Create a paid Minecraft Hunger Games event for up to 100 players with fair gameplay, strong presentation, and reliable operations.

## Core Event Goals
- 100 player capacity
- 4 arena sections / biomes
- 4 cornucopia spawn groups
- 3 lives per player before elimination
- Clear countdown and start rules
- Randomized tiered loot system
- End-to-end registration + payment verification workflow

## Project Tracks
- Server gameplay plugin
- Resource pack + presentation layer
- Backend API + admin panel
- Database + payment verification flow
- Event operations and runbook

## Milestones
- Phase 1: Game rules and match flow
- Phase 2: Lives, spawn assignment, and elimination logic
- Phase 3: Loot tables and chest distribution
- Phase 4: Registration, SQL schema, and API
- Phase 5: UI polish, sounds, and announcement effects
- Phase 6: Staging tests and launch checklist

## Success Criteria
- Players can register and be approved cleanly
- Match starts consistently with balanced spawn assignment
- Lives are tracked correctly across all death causes
- Eliminated players are enforced out of active gameplay
- Admins can audit player/payment/event records

## Open Questions
- Minecraft server stack: Paper/Purpur + plugins vs Fabric/Forge mod stack
- Hosting provider capabilities for required plugins and APIs
- Patreon verification automation vs manual approval
- Preferred admin dashboard stack
