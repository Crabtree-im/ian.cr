# Hunger Games Backend Starter

This folder contains a backend contract starter (no runtime yet).

## Included
- schema.sql: relational schema for players, applications, payments, and match logs.
- openapi.yaml: endpoint contract for registration, payment verification, and status lookup.

## Suggested Next Step
- Implement API with Fastify/Express/NestJS or Spring Boot.
- Add auth for admin endpoints.
- Add rate limiting for public endpoints.
- Add file upload flow for payment screenshot evidence.
