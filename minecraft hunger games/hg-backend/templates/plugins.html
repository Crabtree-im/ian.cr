HungerGamesCore

v0.1.0 — Paper 1.21.1

The server-authoritative Hunger Games plugin. Handles all gameplay logic: match state machine, 3-lives system, spawn assignment across 4 sections, chest loot randomization, and elimination flow. Nothing is handled client-side — the plugin controls everything.

  • Match states: idle → lobby-countdown → spawn-lock → live → finale → finished
  • 3 lives per player — lose all 3 and you're kicked
  • 4 arena sections: Red, Orange, Blue, Purple
  • Deterministic spawn assignment using seeded RNG
  • 60-second spawn-lock countdown — move and die instantly
  • Tiered loot system: Normal chests (4 tiers) and Copper chests (3 tiers)
  • Admin commands: /hg startgames, /hg stop, /hg status, /hg setlives, and more
