# Resource Pack Plan

## Purpose
Provide event visuals/audio while server plugin handles gameplay logic.

## Features
- Custom heart/life visual theme (withered style concept)
- Event sound design (countdown, cannon, stingers)
- Themed UI textures
- Optional overlays for status moments

## Integration Notes
- Resource pack should be required by server settings where possible
- Keep gameplay rules server-authoritative
- Ensure fallbacks for players with audio off

## Asset Buckets
- UI icons/textures
- Ambient and event sounds
- Elimination cannon sound stack
- Optional title screen/event branding

## Open Questions
- Exact Minecraft version target
- Legal-safe source for sound assets
- Final aesthetic direction
